# Sarathy S P – Portfolio

A modern, responsive portfolio website built with **Next.js**, showcasing my projects, skills, and experience as a Computer Science (AI/ML) student.

##  Live Website

https://thesarathy.site

##  Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- GSAP
- Framer Motion
- Web3Forms (Contact Form)
- Vercel

## 🛠️ Run Locally

Clone the repository:

```bash
git clone https://github.com/thesarathy/portfolio.git
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
